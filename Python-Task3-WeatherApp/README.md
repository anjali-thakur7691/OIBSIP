# 🌤️ Live Weather App

A professional Weather Application built using **Python**, **Streamlit**, and **OpenWeatherMap API**.

---

## 📸 Project Preview

![Weather App](weather_app.png)

---

## 🚀 Features

- 🌍 Search weather by city
- 🌡️ Temperature in Celsius & Fahrenheit
- 💧 Humidity
- 🌬️ Wind Speed
- 🤗 Feels Like Temperature
- 📊 Air Pressure
- 🌤️ Weather Icons
- 📅 5-Day Weather Forecast
- 🎨 Clean Streamlit UI

---

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenWeatherMap API
- Requests

---

## 📦 Installation

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
